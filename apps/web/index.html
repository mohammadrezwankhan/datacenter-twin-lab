Datacenter Twin Lab

A reproducible, local-first power-continuity what-if simulator.

A generator fails. How long does the battery last?

In the opening 50 MW example, a 5 MWh battery serves the requested load for 307.8 seconds after utility and generator fail. Utility returns at 900 seconds elapsed. Change the battery reserve to compare depletion and recovery, then export the calculation.

The interactive interface starts automatically when its scripts load. The hosted demo uses JavaScript. Optional Python verification downloads its runtime only when you request it. Calculations run on your device; no account is required.
