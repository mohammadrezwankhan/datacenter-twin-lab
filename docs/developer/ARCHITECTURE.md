## The calculation routes

| Route | Input boundary | Calculation | Result and delivery |
| --- | --- | --- | --- |
| Native planning | Schema 1 `Scenario`, ordered load segments and assumed PUE | Decimal arithmetic in `engine.py` | Synthetic demand estimate, energy-only cost and capacity screen; no supply dispatch |
| Native continuity | Schema 2 `SiteScenario`, validated assets, DAGs and ordered events | Exact `Fraction` network flow and event splitting in `continuity.py` | Completed scenario, interval ledger, event log, warnings and reproducible input hash |
| Browser continuity | Validated JSON request to a fixed JavaScript worker dispatcher | The separate BigInt rational implementation under `js-engine/` | Local result; optional Python/Pyodide comparison is requested separately |
| Local API | JSON request to an app created by `create_app()` | Native Python functions; a two-slot semaphore covers continuity, reports and sweeps | Stateless response; the CLI binds the ASGI server to `127.0.0.1` |
| Infrastructure course | Numeric lesson inputs and source/evidence metadata | Bounded algebraic screens in `infrastructure/screens.ts` | Frozen `infrastructure-screen-1` teaching result, units, hashes and explicit verification limits |
| EMT lesson | Ten bounded circuit/configuration fields | Native TypeScript RK4; separate standard-library Python implementation | Ideal DC-link samples and energy ledger; explicit comparison and step refinement |
| Dynamics studio | One of five study IDs and bounded overrides | Separate Python scientific worker using the research package | Recomputed equilibria, modal/response data, solver diagnostics and JSON/CSV |
| Four-module companion | Embedded `lesson-config.json`, selected kind `cooling` | Closed-form JavaScript teaching proxy in `docs/index.html` | 241 synthetic samples and local configuration/CSV export; separate from the course and continuity model |

## How a continuity result is formed

1. Parse bounded input and reject missing/unknown fields, invalid domains and incompatible topology. Schema 1 and schema 2 are independent contracts.
2. Normalize the accepted scenario for deterministic JSON and SHA-256 identity. An engine version plus input digest identifies a run; a CLI export timestamp sits outside the deterministic result.
3. Apply same-time events in their declared order. Compute availability and generator readiness from the utility asset state. Build the residual network with node/path capacity limits and dispatch utility, generator and battery in that order.
4. End an interval at the earliest regular step, external event, generator-ready boundary, exact battery depletion/full boundary or simulation end. Accumulate exact energy terms before decimal serialization.
5. Return a completed run. Reports re-evaluate validated inputs; result exports, charts and replay consume completed results rather than advancing a physical controller.

See [datacenter_twin/contracts.py](https://github.com/mohammadrezwankhan/datacenter-twin-lab/blob/d8dc3773830a397409a7a9c00a6ffed33c46fb4b/datacenter_twin/contracts.py), [datacenter_twin/topology.py](https://github.com/mohammadrezwankhan/datacenter-twin-lab/blob/d8dc3773830a397409a7a9c00a6ffed33c46fb4b/datacenter_twin/topology.py), [datacenter_twin/continuity.py:308–364](https://github.com/mohammadrezwankhan/datacenter-twin-lab/blob/d8dc3773830a397409a7a9c00a6ffed33c46fb4b/datacenter_twin/continuity.py#L308-L364), [datacenter_twin/continuity.py:522–548](https://github.com/mohammadrezwankhan/datacenter-twin-lab/blob/d8dc3773830a397409a7a9c00a6ffed33c46fb4b/datacenter_twin/continuity.py#L522-L548), [datacenter_twin/browser.py:20–35](https://github.com/mohammadrezwankhan/datacenter-twin-lab/blob/d8dc3773830a397409a7a9c00a6ffed33c46fb4b/datacenter_twin/browser.py#L20-L35) and [the derivations](../math-and-physics/EQUATIONS_AND_DERIVATIONS.md).

## Browser state and worker ownership

The React application keeps draft inputs separate from completed runs. Editing a field marks the current result as stale for that draft; explicit calculation replaces the completed result. Imported scenario/run JSON is revalidated and recalculated rather than trusted as an authoritative result. The demand editor preserves availability events and their equal-time ordering. Course review progress is session state, not a durable learning record. [apps/web/src/App.tsx](https://github.com/mohammadrezwankhan/datacenter-twin-lab/blob/d8dc3773830a397409a7a9c00a6ffed33c46fb4b/apps/web/src/App.tsx), [apps/web/src/ScenarioFiles.tsx](https://github.com/mohammadrezwankhan/datacenter-twin-lab/blob/d8dc3773830a397409a7a9c00a6ffed33c46fb4b/apps/web/src/ScenarioFiles.tsx), [apps/web/src/demand-timeline.ts](https://github.com/mohammadrezwankhan/datacenter-twin-lab/blob/d8dc3773830a397409a7a9c00a6ffed33c46fb4b/apps/web/src/demand-timeline.ts), [apps/web/src/visit-reviews.tsx](https://github.com/mohammadrezwankhan/datacenter-twin-lab/blob/d8dc3773830a397409a7a9c00a6ffed33c46fb4b/apps/web/src/visit-reviews.tsx).

Worker request IDs correlate responses and a fixed envelope restricts fields and body size. A 90-second timeout terminates the shared worker and rejects pending requests. Aborting one request terminates the worker only when no requests remain. A queued worker operation is not evidence of browser parallel computation. Runtime download progress reports observed bytes; compressed or unknown totals are not fabricated percentages. [apps/web/src/worker-envelope.ts](https://github.com/mohammadrezwankhan/datacenter-twin-lab/blob/d8dc3773830a397409a7a9c00a6ffed33c46fb4b/apps/web/src/worker-envelope.ts), [apps/web/src/worker-request.ts](https://github.com/mohammadrezwankhan/datacenter-twin-lab/blob/d8dc3773830a397409a7a9c00a6ffed33c46fb4b/apps/web/src/worker-request.ts), [apps/web/src/runtime-progress.ts](https://github.com/mohammadrezwankhan/datacenter-twin-lab/blob/d8dc3773830a397409a7a9c00a6ffed33c46fb4b/apps/web/src/runtime-progress.ts).

The ordinary JavaScript worker supports continuity/planning/report/catalog operations. EMT imports its own native module; Python `dispatch_json` additionally exposes `emt`. Research uses a separate `research` worker request and scientific archives. The local HTTP API has no EMT or research REST route. ## Repository map

| Area | Responsibility | Change boundary |
| --- | --- | --- |
| `datacenter_twin/` | Native contracts, models, reports, CLI and optional API | Application/scientific changes require their own focused tests and review |
| `datacenter_twin/research/` | Adapted supplied equations and guarded study wrappers | Preserve provenance and distinguish missing original MATLAB/measurement inputs |
| `apps/web/src/` | Course state, worker adapters, native model mirrors, charts and teaching scenes | Preserve result/draft boundaries and Python comparison contracts |
| `apps/web/` build modules | Static lesson discovery, metadata, security headers and local evidence staging | Root/subpath URLs, source hashes and public-asset allowlists matter |
| `data/` | Synthetic fixtures, catalog assumptions and historical evidence | Dates and unknowns remain explicit; historical packets stay immutable |
| `docs/` | Existing contracts/tutorials, offline companion and this reference package | Static documentation is copied by the existing Pages pipeline |
| `assets/engineering-hero/` | Original decorative presentation plus separately licensed vendor files | Animation is not model evidence or a physical result |
| `scripts/`, `tests/`, `.github/` | Reproduction, build, platform and security checks | Preserve check names, tolerances, supported matrix and deployment guards |
