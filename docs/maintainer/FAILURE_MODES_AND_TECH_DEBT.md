## Operational failures worth retaining

Numerical failures must preserve study/configuration and actual diagnostics. Nonconvergence, a nonfinite result, a conditioning guard or an invalid event graph must not turn into a zero-filled “successful” report. Runtime download integrity failure is terminal for that artifact. A worker timeout can reject multiple pending requests, so retain the failed operation ID and applied configuration. Unknown rates remain unknown.
