## Scope decisions

The repository supports local planning, aggregate continuity, bounded educational infrastructure screens, an ideal EMT lesson and five adapted dynamics studies. It supplies explicit inputs, labels, hashes, exports and software verification. It does not supply a facility-control system, multi-tenant service, live telemetry pipeline, calibrated reliability result or equipment-selection authority. Infrastructure educational publication retains Engineering HOLD. [Implemented model limits](../math-and-physics/ASSUMPTIONS_AND_LIMITS.md), [docs/releases/v2.0.0-publication-decision.md](https://github.com/mohammadrezwankhan/datacenter-twin-lab/blob/d8dc3773830a397409a7a9c00a6ffed33c46fb4b/docs/releases/v2.0.0-publication-decision.md).

The present documentation task updates explanations, traceability, navigation and maintenance/recovery planning. It preserves application/science/test/workflow/dependency/license behavior and historical evidence. A roadmap item is a proposal for later scoped work, not authorization to implement a new model or operational service now.

## Decisions that require a new contract

Before using measured data, establish permission, provenance, units/bases, uncertainty, representative conditions and validation responsibility. Before a shared service, define authentication/authorization, isolation, persistence and abuse boundaries. Before a physical connection, define a separate engineering/safety/control scope. Before depositing an archive, verify the real account, artifact and metadata; do not invent a DOI or endorsement. These remain conditional planning boundaries, not supplied capabilities.

## Keep provenance inspectable

Changes should preserve source locators, versioned historical assets and precise claim classes. Cite the exact configuration/source used; a moving branch or current badge is insufficient for an old result. Retain unresolved findings and failures rather than smoothing them into a “green” status. Use the existing contribution, support and security routes without adding fabricated response promises.
